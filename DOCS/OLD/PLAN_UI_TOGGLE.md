# 実施計画書：GGAdviser UIのトグル切り替え（ON/OFF機能）の導入

## 1. 目的
`map-making.app` において、解析（GGAdviser）を使用しない時でも快適に利用できるよう、UIの表示・非表示を切り替えるトグルボタンを追加します。これにより、必要な時だけ解析用のインターフェース（Split View, Geminiパネル等）を呼び出すことが可能になります。

## 2. 実装方針
- **状態の永続化:** `chrome.storage.local` に `gg_ui_enabled` というフラグを保存し、タブを閉じたりリロードしたりしても設定が維持されるようにします。
- **トグルボタンの設置:** `map-making.app` のヘッダー部（アイコンボタンの右隣）に、直感的なSIDEBAR ON/SIDEBAR OFF切り替えボタンを設置します。
- **動的な表示制御:**
    - **OFF時:** サイドパネル（Gemini）と解析ボタンを非表示にし、地図を全画面表示に戻します。
    - **ON時:** 従来の Split View レイアウトを適用します。
- **後方互換性:** デフォルトでは `ON` 状態とし、既存のユーザー体験を壊さないように配慮します。

- [x] `split_view.css` に、UIが無効化された際のオーバーライドスタイル（`.gg-ui-disabled` クラス等）を追加。
- [x] **追加要件: フローティングレイアウトの採用**

### 工程 3: トグルロジックと状態管理の実装 <!-- id: 3 -->
**目標:** ボタン押下でストレージの状態を更新し、UIに反映させる。

- [x] トグル時に `chrome.storage.local` に新しい状態を保存する処理を実装。
- [x] `applyUIState` メソッドを実装し、状態に応じて `body` のクラス追加・削除とボタンの見た目を更新。
- [x] 初期化時に、最後に保存された `gg_ui_enabled` の値を読み込んで適用するロジックを実装。
- [x] **検証ポイント:**
    - [x] ボタンクリックで実際に地図とパネルの表示・非表示が切り替わることを確認。
    - [x] ページリロード後（シミュレーションでは初期読み込み）に前回の状態が維持されることを確認。

**判定:** 不要（工程 3 のパネル非表示に包括されるため削除済）。

## 4. 全体検証プロセス

1. **初期ロード:**
   - 拡張機能を更新後、`map-making.app` を開き、デフォルトでUIがONであることを確認。
2. **OFFへの切り替え:**
   - 新設されたヘッダーボタンを押し、Geminiパネルが消えて地図が広がることを確認。
3. **永続性の確認:**
   - ページをリロードし、UIがOFFのままであることを確認。
4. **ONへの復帰:**
   - 再度ボタンを押し、元の Split View レイアウトに戻ることを確認。

---
> [!NOTE]
> ユーザーが「普通の Map-making app として使いたい」というニーズを最優先し、OFFの状態では拡張機能の影響を最小限（ボタン一つのみ）に抑えます。
