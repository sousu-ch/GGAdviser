# グリッドオーバーレイ & 画像インジェクション 実装計画書

## 1. 目的とゴール
Gemini の解析精度とユーザーの視認性を向上させるため、以下の2点を実現します。
1.  **グリッド合成**: ストリートビューなどのキャプチャ画像に、座標特定用のグリッド線とラベル（A1, B2 等）を自動合成してから Gemini に送信します。
2.  **回答への画像挿入**: Gemini が回答した直後に、その解析に使用した「グリッド付き画像」を拡張機能が自動でチャット画面（回答の直下）に挿入します。

これにより、ユーザーは「A-2 の看板」といった Gemini の指摘を、直感的に画像上で確認できるようになります。

## 3. 残課題・検討事項
## 4. Future Improvements / Pending Check
- **Prompt Readability**: 
    - ユーザーより「`[画像1: A-2]` のような記述が増えすぎて読みづらい」との懸念あり。
    - Phase 3 実装完了後、システム的な検知精度（自動ハイライト等）と、人間にとっての可読性のバランスを見てプロンプトを緩和・調整する。
- **Canvas のフォント**: Service Worker 上の OffscreenCanvas では、システムフォントの利用に制限がある可能性があります。必要に応じてBitmapフォントの利用などを検討します。
- **画像サイズ**: 解析用（高画質）と表示用（適度なサイズ）でリサイズが必要か、パフォーマンスを見ながら判断します。
