# Gemini Web UI 限定ミニマル化 実装計画書 (v2.2)

## 1. 目的とゴール
Geoguessr の支援ツールとしてサイドバー（iframe）に Gemini を表示する際、不要な UI 要素（ロゴ、挨拶、ナビゲーション）をすべて隠し、チャット入力欄と回答のみが並ぶ極限までシンプルな表示を提供します。
一方で、通常のブラウザタブで Gemini を開いた際はフル機能の UI を維持し、ユーザーの通常の AI 利用を妨げないことをゴールとします。

---
