# WIDE MODE 機能統合計画書

`mmapp_custom` の機能を GG Adviser に統合し、地図エディタのレイアウトを最適化する「WIDE MODE」ボタンを追加します。

## 概要
- **目的**: 地図とストリートビューを上下並びに固定し、画面を最大限に活用する機能を GG Adviser の一部として提供する。
- **機能**:
  - 「WIDE ON/OFF」ボタンによるレイアウト切り替え。
  - 地図とストリートビューの境界線のリサイズ機能。
  - AI パネル（AI ON/OFF）とは独立した状態管理。

---
