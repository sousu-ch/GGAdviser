# GGAdviser 配信向け拡張機能案（Streaming Focus）

GeoGuessr配信を盛り上げ、配信者と視聴者のコミュニケーションを円滑にするための機能案です。

---

## 1. 視聴者インタラクション連携 (Viewer Engagement)

視聴者がコメントでゲームに参加できる機能です。

*   **コメント連携グリッドハイライト (Twitch/YouTube Integration)**
    *   **概要**: 配信コメントで「`A-2`」「`check B3`」などの座標指定があると、ゲーム画面上の該当グリッドが**ポワンと光る**。
    *   **効果**: 「あそこ見て！」という視聴者の指示がダイレクトに伝わる。ラグのある配信でも位置指示が明確になる。
    *   **実装**: TMI.js (Twitch) などを利用したコメント監視Bot機能。

*   **視聴者投票オーバーレイ (Country Vote)**
    *   **概要**: AIが解析中、あるいは配信者が迷っている間に、視聴者が正解の国を投票できる。
    *   **表示**: 画面端にリアルタイムで投票グラフを表示。
    *   **効果**: 一体感の醸成。

## 2. 配信画面演出 (OBS & Overlay)

OBSなどの配信ソフトでの利用を前提としたUI拡張です。

*   **OBS専用「AI解説ウィンドウ」 (Audience Only View)**
    *   **概要**: 配信者（プレイヤー）の画面には**AIの答えを表示せず**、別ウィンドウ（または別出力）にだけAIの全解析結果を表示するモード。
    *   **ユースケース**: 配信者は自力で解こうと努力し、視聴者はAIのネタバレ（「正解はフランスです」）を見ながら「あー、そこフランスの特徴だよ！」とコメントで匂わせる遊びができる。
    *   **Green/Blue Back**: クロマキー合成用に背景を単色にするモード。

*   **ダイナミック・フォーカス枠**
    *   **概要**: AIが「決定打」として挙げた部分（例：標識）を、自動的にズームアップしてワイプ（PinP）で表示する。
    *   **効果**: スマホで見ている視聴者にも、細かいメタ情報が見やすくなる。

## 3. 実況・解説アシスト (AI Commentary)

*   **AI読み上げ実況 (TTS Integration)**
    *   **概要**: AIの生成したテキストを、VOICEVOXやずんだもんなどのTTSに読み上げさせる。
    *   **効果**: 配信者が無言で集中している時でも、AI相棒が喋って間を持たせてくれる。「相棒のAIと協力プレイ」という配信スタイルが確立できる。

*   **「撮れ高」自動クリップ**
    *   **概要**: AIの推測が大外れした時や、逆にスーパープレイ（超難問正解）が出た時に、自動でチャットに「ｗｗｗ」や「Nice!」のようなエフェクトを飛ばす、あるいはクリップ作成のマーカーをつける。

---

## 4. UI/UX カスタマイズ (Theming)

*   **ストリーマーテーマ**
    *   **概要**: グリッドの色、フォント、枠のデザインを配信のブランドカラーに合わせてカスタマイズできる機能。
    *   **例**: ネオン調、レトロゲーム調、ホラー調など。

---

## 優先度別ロードマップ案

1.  **Phase 1: コメント連携グリッド (Twitch)**
    *   視聴者の「参加感」に直結するため、最もインパクトが大きい。
2.  **Phase 2: Audience Only View (OBS用)**
    *   「配信者は見えないが視聴者は見える」という非対称な情報状態は、配信エンタメの鉄板。
3.  **Phase 3: AI読み上げ (TTS)**
    *   VTuber活動などとの親和性が高い。

特に「Phase 1」と「Phase 2」の組み合わせで、**「視聴者がAIの答えを見ながら、まだ気づいていない配信者にグリッド番号でヒントを出す」** という新しい遊び方が生まれます。これは非常に強力なコンテンツになるはずです。
