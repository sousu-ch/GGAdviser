# 実現性検討: 「画像から始まる」探索型学習 (Image-First Interaction)

ユーザー様より提案のあった、「画像上のハイライトから解説にアクセスする」アプローチ（逆引き型インタラクション）についての実現性と実装案の検討結果です。

## 1. コンセプト定義: "Discovery Mode"

従来の「解説を読む -> 画像を確認する」というフローを逆転させ、「画像上の違和感を探す -> 解説で答え合わせをする」という、よりゲーム的かつ直感的な学習体験を提供します。

### ユーザー体験 (UX) の流れ
1.  **Start from Image**: ユーザーはまず4方向の画像を見る。
2.  **Clue Indicators**: AIが解説内で言及したグリッド（例: C-3, A-1）が、うっすらと**「ここにヒントあり」**という光り方をしている。
    *   *未読の宝箱を探すような感覚。*
3.  **Active Exploration**: 気になった光るマスをクリックする（例: 「この植物なんだろう？」と思ってクリック）。
4.  **Instant Insight**: クリックした場所のすぐ近くに、**その場所に関連する解説文だけ**がポップアップ（またはハイライト）される。
    *   例: **[C-3]**「この赤土はブラジルのミナスジェライス州特有のものです。」

---

## 2. 技術的実現性 (Technical Feasibility)

**結論: 実現可能性は「高」です。**
既存のシステム（テキスト解析ロジック）を少し拡張することで実装可能です。

### 必要な技術要素と課題

#### A. テキストと座標の紐付け (Parsing Context)
**課題**: 現在のロジックは「座標文字列」を見つけてリンクにするだけですが、この機能には「その座標が**どの文章に属しているか**」を理解する必要があります。
*   **解決策**:
    *   AIの回答フォーマットは箇条書き（`-`）がベースになっているため、行単位でのパースが容易です。
    *   `[画像1: A-1]` というタグが含まれる**行全体（または直前の文）**を抽出し、その座標の「メタデータ（解説テキスト）」として保持します。

#### B. 座標データの逆方向通信 (Reverse Data Flow)
**課題**: 現在は `ImageInjector` (Content Script) -> `Background` -> `SplitViewManager` (Image) という一方通行に近いフローです。
*   **解決策**:
    *   AIの解析完了時、`ImageInjector` が全文をスキャンし、`MappingData { coordinate: "A-1", text: "..." }` のリストを作成。
    *   このリストを `SplitViewManager` に一括送信し、グリッド描画時に「ヒントありフラグ」として使用します。

#### C. UI表示 (Tooltip / Popover)
**課題**: 狭いグリッド上で長い解説をどう見せるか。
*   **解決策**:
    *   **ツールチップ**: マウスホバーで簡易表示。
    *   **インテリジェント・スクロール**: 画像をクリックすると、左側のチャット画面が自動的にスクロールし、該当する解説行をハイライトする（これが最も実装が軽く、読みやすい）。

---

## 3. 具体的な実装案 (Proposed Design)

### 機能名: "Meta Hunter Mode" (メタ・ハンターモード)

#### フェーズ1: 「ヒントマップ」の実装
1.  **解析ロジック**: 正規表現で `(行頭の - または文頭).*?(\[画像\d+: [A-E]-[1-5]\])` のパターンを抽出し、座標とテキストをペアリング。
2.  **グリッド描画**: データがあるマスには、薄い「？」マークアイコンを表示（または枠線をゴールドにする）。
3.  **クリック動作**: クリックすると、左側のチャットパネルがその行まで自動スクロールし、一時的に背景色を黄色にして強調する。

#### フェーズ2: 「インゲーム解説」の実装
1.  **ポップアップ**: グリッドをクリックした瞬間、画像の上に半透明の黒帯オーバーレイを出し、そこに解説文（要約）を直接表示する。
    *   視線移動がゼロになり、没入感が最大化します。

---

## 4. 期待される学習効果

*   **「気づき」のトレーニング**: 文字で答えを見る前に、「画像のどこを見るべきか」だけが示されるため、自分で考える余地が生まれます。
*   **探索の楽しさ**: 「まだ光っているマスがある＝見落としているメタがある」ということが可視化されるため、全てのヒントを回収したくなります（コンプリート欲求）。

この「画像から入る」アプローチは、特にご要望のあった「クイズ的要素」や「学習効率」の観点から非常に合理的です。まずはフェーズ1（クリックでチャット該当箇所へジャンプ）から実装することをお勧めします。
