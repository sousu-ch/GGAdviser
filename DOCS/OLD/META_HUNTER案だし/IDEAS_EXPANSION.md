# GGAdviser 拡張機能案：学習プラットフォームへの進化

単なる「正解表示ツール」から、「プレイヤーのスキルを能動的に向上させるコーチングプラットフォーム」へと進化させるための機能案です。

---

## 1. アクティブ・ラーニング（能動的学習）機能

AIが一方的に教えるのではなく、ユーザーに考えさせるモードです。

*   **コーチングモード（クイズ形式）**
    *   **概要**: 答えをすぐに出さず、AIが「この植生を見てどう思う？」「太陽の方角は？」と問いかける。
    *   **フロー**: 解析開始 -> AI「ヒント: 電柱の形に注目してください」 -> ユーザーが考える -> 「正解を表示」で解説解禁。
    *   **効果**: 思考定着率の向上。

*   **「なぜ違う？」対話機能**
    *   **概要**: ユーザーが予想した国を入力すると、正解との違いを比較解説する。
    *   **例**: ユーザー「フィンランドだと思う」 -> AI「フィンランドに似ていますが、この黄色い中央線とボラードの形状はむしろノルウェーの特徴です」。
    *   **効果**: 誤答パターンの矯正。

## 2. ナレッジ・マネジメント（知識の蓄積）

プレイ中に得た知識を自分だけの「攻略本」として蓄積する機能です。

*   **My Meta Pokedex (場所・メタ図鑑)**
    *   **概要**: AIが解説した「決定打（Silver Bullet）」をワンクリックでスクラップ保存。
    *   **UI**: サイドバーに「保存」ボタン。保存された情報は「ボラード」「植生」「ナンバープレート」などのタグで分類され、後で検索・閲覧可能。
    *   **効果**: 復習効率の最大化。

*   **弱点分析レポート**
    *   **概要**: 過去の履歴を集計し、「南米での正答率が低い」「ボラードの見落としが多い」などの傾向を分析（※要履歴保存機能）。
    *   **効果**: 重点的に学習すべきエリアの可視化。

## 3. インゲーム支援（プレイ中の強化）

*   **リアルタイム・コンパリスン（比較オーバーレイ）**
    *   **概要**: AIが「フランスのボラードです」と言った時、画面上に「典型的なフランスのボラードの図」を半透明で重ねて表示し、実物と比較できるようにする。
    *   **実装難易度**: 高（参照画像のDBが必要）。ユーザーがスクリーンショットを撮影して自分のDBを作る形なら可能かも。

*   **コンパス・太陽アシスト**
    *   **概要**: 画面上の太陽の位置から、正確な方角や緯度の目安を計算してグリッド上にガイドを表示する。

## 4. 外部連携・ソーシャル

*   **Map-making.app 連携強化**
    *   **概要**: AIが見つけた「良問」を、そのまま Map-making.app のカスタムマップに追加するAPI連携。
    *   **効果**: 自分の学習用マップ作成の自動化。

*   **Plonk It / GeoHints リファレンス**
    *   **概要**: 解説の中に、該当する Plonk It や GeoHints の解説ページへのリンクを自動生成する。
    *   **効果**: 信頼できる外部ソースでの裏付け。

---

## 推奨ロードマップ案

1.  **Phase 1: My Meta Pokedex (保存機能)**
    *   解説の有用な部分をローカルに貯められるようにする。これが最も学習効果が高い。
2.  **Phase 2: コーチングモード（Hidden Mode）**
    *   解説を最初は隠し、「どこを見るべきか」のヒントだけ出すモードの実装。
3.  **Phase 3: 「なぜ違う？」対話**
    *   ユーザー入力を受け付けるチャットUIの拡張。

いかがでしょうか？特に「保存機能」と「コーチングモード」は、学習アプリとしての価値を大きく高めると思われます。
