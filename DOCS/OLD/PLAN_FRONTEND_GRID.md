# フロントエンドによるグリッド描画と高画質表示の実装計画書

## 1. 目的とゴール
現在の実装では、画像にグリッド線を直接書き込み、トークン節約のためにリサイズしたものを表示している。しかし、これでは地図の細かい文字が潰れて読めないという問題がある。
本計画では、**AI用（分析用）** と **人間用（表示用）** のデータ処理を分離し、ユーザーにはオリジナル高画質画像を表示しつつ、HTML/CSSで動的にグリッドをオーバーレイ表示することで、視認性と操作性を劇的に向上させる。

**ゴール:**
1.  **高画質化**: 表示画像をキャプチャ時のオリジナル画質（4K等）にする。
2.  **操作性向上**: グリッドのOn/Offトグル機能を提供する。
3.  **視認性向上**: ハイライトを「塗りつぶし」から「枠線点滅」に変更し、地図情報を隠さないようにする。

## 3. 残課題・検討事項
- **Sync機能のUX**: 「閉じる」と同時に同期するのが良いか、明示的なボタンが良いか。今回はユーザー提案通り「閉じる（画像クリック）」で同期を試すが、誤操作防止のため「同期して閉じる」アイコンを別途設ける案も検討可。
- **超高解像度画像**: 8K等でも動作することを確認済みだが、メモリ消費には引き続き留意。
