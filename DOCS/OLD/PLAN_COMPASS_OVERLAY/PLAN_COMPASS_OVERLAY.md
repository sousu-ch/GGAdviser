# コンパスオーバーレイ（N/E/S/W）実装計画書

## 1. 目的とゴール
サムネイル画像に「方角（N, E, S, W）」をオーバーレイ表示し、ナビゲーションを直感的にする。
また、AIプロンプトの記述を英語表記（N/E/S/W）に統一し、サムネイルと解説の整合性を高める。
**既存機能（Grid切替、画像切替）への悪影響（クリック阻害など）を完全に回避する。**

---
