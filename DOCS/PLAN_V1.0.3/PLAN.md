# v1.0.3 権限リクエスト改善計画 (Optional Permissions)

## 1. 目的とゴール
ユーザー体験とプライバシーのバランスを最適化する。
- **現状**: インストール時に `<all_urls>` (全Webサイトへのアクセス) という強力な権限を要求し、ユーザーに不安を与える可能性がある。
- **ゴール**: 
    1. インストール時は「必要最小限」の権限のみにする。
    2. **Optionsページに「権限設定」セクションを新設**し、現在の許可状態を可視化する。
    3. 設定保存時、または明示的なボタンクリックで権限を付与できるフローを確立する。
    4. これにより、v1.0.2 からの既存ユーザーも、新規ユーザーも迷わずに権限設定を行えるようにする。

## 3. 残課題・検討事項
- `chrome.permissions.remove` 機能は実装しない（Chromeの設定画面から削除できるため不要）。
- 将来的には `activeTab` への完全移行も再検討するが、現状のUX維持のためにはこの Optional 方式が最適解。
