name: reload_extension
description: 開発中の拡張機能を安全かつ確実にリロードするための汎用スキル。
---

# 概要
このスキルは、開発中の拡張機能を `chrome://extensions` ページからリロードします。
特定のプロジェクト名に依存せず、`manifest.json` や「解凍済み (Unpacked)」状態に基づいて対象を自動特定します。

# 手順
あなたは拡張機能をリロードするために、以下の手順を実行します。

1. **対象名の特定 (Optional)**:
   - カレントディレクトリ（またはその近辺）の `manifest.json` を探し、名前 (`name`) を取得します。
   - 名前が見つかった場合は、それをリロード対象名として記憶します。

2. **スクリプトの準備**:
   - `scripts/reload_extension.js` の内容を読み込みます。

3. **ブラウザ操作**:
   - `mcp_chrome-devtools_new_page` で `chrome://extensions/` を開きます。
   - `mcp_chrome-devtools_evaluate_script` を使用して、読み込んだスクリプトを実行します。
   - **引数の渡し方**: スクリプトは関数を返すため、以下のようにラップして呼び出すか、マニュアルで変数置換を行ってください。
     - 例: `(NAME_FROM_MANIFEST) => { ... }("特定した名前")`
     - または単に引数なしで実行（その場合、すべての「解凍済み」拡張機能がリロードされます）。

4. **結果確認と後処理**:
   - `"SUCCESS: ..."` のメッセージを確認します。
   - テスト対象のページをリロードすることを忘れないでください。

# 禁止事項
- `browser_subagent` の使用。
- 開発用（Unpacked）以外の一般拡張機能の強制リロード。
