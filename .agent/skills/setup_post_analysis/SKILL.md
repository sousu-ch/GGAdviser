# 概要
このスキルは、GGAdvice拡張機能における **「解析実行後 (Post-Analysis)」** の動作検証を行うためのセットアップを自動化します。
CORS制限やDOMスキャンのコストを回避するため、`mcp_chrome-devtools_list_console_messages` を使用して拡張機能が出力する特定の完了信号を監視します。

**⚠️ 注意事項**: 
このスキルは自動的に解析ボタンを押してしまいます。初期状態のUIや、解析前の動作を検証したい場合には使用しないでください。

### 手順
1. **ページ遷移**: 
   - `mcp_chrome-devtools_navigate_page` で対象のマップページへ移動。

2. **解析のトリガー (Javascript 実行)**:
   - `scripts/trigger_analysis.js` を実行し、座標入力と解析を開始します。
   - **重要**: 監視の誤検知を防ぐため、スクリプト内でまず既存の手がかり表示（`#gg-meta-panel`）を**クリア（削除）**してから解析を開始します。

3. **完了の監視 (Orchestration)**:
   以下の手順で、ブラウザの外部から DOM の状態を監視します。

   - **監視ツール**: `mcp_chrome-devtools_evaluate_script` によるDOM監視
   - **完了判定基準**: セレクタ `.gg-clue-li` に一致する要素が1つ以上存在すること
     - **理由**: コンソールログ監視は、拡張機能の実行コンテキスト（Main/Isolated）によって取得漏れが発生する可能性がありますが、DOMの状態はコンテキストに関わらず確実に検知可能です。
   - **確認用コード**: `() => document.querySelectorAll('.gg-clue-li').length > 0`
   - **監視間隔**: **1秒おき**
   - **タイムアウト**: 
     - **最大60秒** 経過しても要素が現れない場合は、失敗として処理を中断し報告します。

4. **準備完了**:
   - 手がかり要素の出現を確認後、検証（アイコンの視認、クリック動作の確認など）へ移行します。
